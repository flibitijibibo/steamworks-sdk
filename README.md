# Steamworks SDK

This repository tracks the API headers and client libraries for the Steamworks
SDK. This can be useful for tracking changes and downloading specific SDKs for
CI, including GitHub Actions.

# How to Use

Each revision is given its own tag, so builders that only need a single version
can use a specific command to avoid downloading the entire history:

```
git clone --depth 1 --branch 1.26a https://github.com/flibitijibibo/steamworks-sdk
```
